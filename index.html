How to add a page

An HTML page: put the .html file anywhere in pages/ (a sub-folder becomes its group), then push. The GitHub Action runs tools/build_pages.py, which adds it to the list automatically. To set a nicer title or description, edit its entry in pages.json.

A link to another site: add an entry with url instead of path to pages.json:

{
  "title": "My other results",
  "url": "https://example.com/results.html",
  "group": "External",
  "description": "Opens in a new tab.",
  "tags": ["external"]
}
